# U12 — Crafter

Scope: U12 ([ADR 0060](../decisions/0060-crafter.md)). Minecraft 1.21.1, NeoForge
21.1.252, Java 21, macOS arm64.

Implemented (U12a `2bd3cb7` and this commit):

- `factorycore:crafter` is one block with `facing` and one `CrafterEntity` that
  accepts crafting-table and processing patterns in its nine slots. Crafting-table
  patterns run with no machine; processing patterns use the faced machine. Hoppers
  reach the patterns from every face except the machine's. The recipe is the old
  Crafting Unit's.
- The `crafting_unit` and `crafting_interface` blocks, items, block-entity types,
  recipes, loot tables and assets are removed, with no aliases (UD7).
- SPEC R02 lists one Crafter role. The player guide recipe table and crafting
  sections, the crafting module doc, the asset inventory, guide pages 8 and 9, the
  tooltips and job/status text use "Crafter".

Tests (the requirement changed; coverage moved with it):

- All crafting, processing, journal, branch, keep-stock, wireless-crafting and
  program tests now place the Crafter.
- Recipe expectations: 22 recipes. The later-tier kit drops the removed
  Crafting Interface recipe's exact inputs, and the progression stage lists
  `crafter`. Asset bound: ≥14 blocks. The presentation tooltip floor is ≥13
  described items, since two described blocks became one.
- New `crafterHoldsBothPatternKindsAndKeepsItsMachineFaceFree`.

Checks:

- `python3 scripts/verify.py` PASS; all 354 required GameTests pass.
- Under the GUI lock and `caffeinate`: `runPresentationClient` PASS (after the floor
  change), `runTerminalRestartClient` PASS (terminal and restart) and `runJeiClient`
  PASS.

Open: the display name "Crafter" matches the UD4 table, but vanilla 1.21 also has a
"Crafter" block. A rename is a lang-only change for U15 if wanted.
