# H1 — Panel kit

Scope: playtest plan H1 (K1, K3; gate HD3). Minecraft 1.21.1, NeoForge 21.1.252, Java 21
(`~/.local/jdk-21`), Linux x86-64 on Wayland.

Implemented:

- `platform/client/ui`: `PanelLayout` (fixed 176/230 px panels, 7 px edge, 18 px rows and slots,
  4 px gaps, a footer reserved at the bottom, and rows that throw rather than overflow), `Rect`,
  `Panels` (sprites and dark text colors for the light face), `ChoiceButton` (the selected option
  is pressed in copper) and `ToggleButton` (a ticked box and label; narration includes the state).
  `StatusStrip.drawOnPanel` draws the status in the kit's colors. [ADR 0064](../decisions/0064-panel-kit.md).
- Sprites `panel`, `inset`, `slot`, `choice_selected`, `checkbox` and `checkbox_checked` are
  generated by `tools/art/generate_art.py` into `textures/gui/sprites`, with nine-slice `.mcmeta`
  files where they stretch.
- The Gateway screen is the first screen on the kit. It is a 230×227 panel with the four presets
  as a choice row and the 17 permissions as toggles that always show the current policy. Under a
  preset the toggles are locked, and Custom unlocks them. The description of the selected choice
  sits below the toggles, and the read-only notice shows in amber. The footer holds the status
  and **Access…**. Column headers may use three lines.

Checks:

- `PanelLayoutTest` (6 cases): row stacking, footer reservation and overflow refusal, vanilla edge
  alignment, `fit` sharing spare width and shrinking, equal columns and right-aligned actions.
- `test_art.py`: the 16 px rule now applies to block and item textures only. A new case checks
  that GUI sprites are RGBA PNGs and that each nine-slice border leaves a centre to stretch.
- `AssetReferencesTest.everyScreenSpriteIsUsedByThePanelKitAndExists`: the `Panels` sprite IDs
  and the generated sprite files match exactly.
- `runPresentationClient` PASS. `gateway-policy` and `gateway-custom` fit at scales 1–4 in the
  1708×960 minimum (panel 230×227 in 427×240 at scale 4). I inspected
  `gateway-policy-scale-4.png` and `gateway-custom-scale-1.png`.
- `runTerminalClient` PASS. A real click on the first "View" toggle flips exactly the first bit,
  the headers fit in `HEADER_LINES`, and no controls overlap.
- `runMultiplayerCheck` PASS. The owner toggled a bit; the second player sees the locked,
  read-only view (`stranger-policy-readonly.png`, inspected) and a forged click is refused.
- `python3 scripts/verify.py --full` PASS on the second run: 399 required GameTests and every
  release suite. The first run crashed the GameTest server in the unrelated
  `BufferImportGameTests.auditedBufferRepairRetainsInventoryAndRequiresAuthorizedPresetReapply`
  with "Buffer network is offline". That test idles 50 ticks after the network is ready and then
  configures the buffer, the rebuild race recorded under parity gate PD7. This change touches
  no server code.

Limits: only the Gateway screen uses the kit. The Terminal (H2) and the other device screens
(H3) still use the dark style. Tabs are specified in ADR 0064 but are built with H2.
