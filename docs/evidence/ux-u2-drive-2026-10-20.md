# U2 — Drive screen — 2026-10-20

Scope: P2/P6, partial A02/A11/A13 evidence. Minecraft 1.21.1, NeoForge 21.1.252,
Java 21.0.12, macOS 15.3.1 arm64 (Apple M1), framebuffer 1708×960.

Empty-hand use opens a four-bay screen with tier, exact identity count, used/capacity
bar and player inventory. Cursor clicks install or remove a chosen cell; Shift-click
removes to inventory, or installs from inventory into the first empty bay. Modules
upgrade a bay's cell through the existing detach/resize/attach ownership path.
Backing UUID, contents, reservations and components survive; lease generations
advance and routing revalidates. Wrong-order modules leave the lease and input
unchanged. Sneak-use removal and portable offhand upgrades remain supported.
No persistence format or resource-transfer authorization changes are introduced.

`DriveScreenGameTests` covers chosen-bay install/removal, occupied-bay rejection,
inventory removal, populated/reserved/named cell upgrades with module consumption,
repeated and lower-tier module rejection, the finite fluid ceiling, full-drive
rejection, and distant/closed menu mutation denial. Type counts read the canonical
ledger's map size without copying or enumerating resource metadata.
