# D06 balance version two: automated recipe and progression evidence — 2026-10-18

Automated evidence for [ADR 0048](../decisions/0048-final-balance.md): D06 and partial
A02/A17. Minecraft 1.21.1 / NeoForge 21.1.252 / Java 21, macOS arm64, headless. Only
Minecraft, NeoForge, Factory Core and the excluded GameTest fixture mod are loaded.

## Human playtest skipped

**No human survival
playtest was run.** The checks below replace it only for these questions:

- Can every item be reached from vanilla materials?
- Are the stages ordered?
- Do the recipes really craft?
- Do the numbers match the code?

They say nothing about pacing, fun, onboarding clarity or a working endgame factory.

## Commands and results

Commands:

- `./gradlew spotlessApply`
- `python3 scripts/verify.py`, which runs spotless, PMD, ArchUnit, JVM tests and the
  native GameTest server through `./gradlew build`.

Results:

- `python3 scripts/verify.py`: PASS. That covers 317 JVM tests (0 failures) and the
  save-order and staging servers.
- `RecipeProgressionTest`: 7 tests, 0 failures.
- `GuidePagesTest`: 2 tests, 0 failures. It now requires 15 pages and the words
  "Progression" and "Nether star".
- GameTest server: 280 required tests, 0 failures, errors or skips. 277 existed before
  this change. The new tests are:
  - `everyRecipeResolvesUniquelyAndEveryRegisteredItemIsObtainable`
  - `starterNetworkCraftsFromAVanillaInventory`
  - `laterTiersCraftInOrderAndReachAnInfiniteCell`
- `StorageDriveGameTests.vanillaRecipesPreservePopulatedCells` now expects the quartz
  Expansion Module and still passes.

## What the checks showed

- All 23 `factorycore` crafting recipes load. Each canonical grid resolves to its own
  recipe and not a vanilla or sibling one. Each yields an unbound, registered item and
  has a recipe-book unlock.
- 32 registered items: 23 have a recipe; 9 come from module upgrades or pattern
  encoding. No item lacks a source.
- A working starter base comes out of a real crafting table from exactly 39 iron,
  35 redstone, 12 copper, 13 glass, 3 hoppers, a chest, a furnace, a bucket, a book and
  4 paper. The base is a controller, 8 cables, a drive, item and fluid cells, a
  terminal, a buffered interface, a connector, a machine interface, a generator, a bank,
  a guide and 4 Blank Patterns.
- The Expanded, Advanced and Endgame items craft in dependency order from exactly
  45 iron, 16 gold, 27 redstone, 3 quartz, 5 ender pearls, a crafting table, a hopper, a
  repeater, 3 glass, 5 copper, a chest, 8 diamonds, 9 netherite ingots, 2 eyes of ender
  and a Nether star. The Wireless Terminal consumes a crafted Storage Terminal, and the
  link endpoints consume crafted access points. The crafted Expansion, Advanced and
  Infinite modules upgrade a crafted Starter Item Cell to Infinite, consuming one module
  each.
- Mutation check during development: changing the Expansion Module back to a diamond
  made two `RecipeProgressionTest` tests fail. The Advanced Module no longer came at a
  later stage, and the stage table no longer matched. The file was then restored.

## Not covered

- The human survival playtest. Pacing and whether upkeep feels fair are unverified,
  especially link ends needing two generators each.
- Bank upgrades starting from a crafted bank. They need a placed-then-broken bank
  lease, which `EnergyBankGameTests` covers separately.
- Using encoded patterns is covered by the crafting GameTests, not by these tests.
- Gateway depth configuration was implemented subsequently and is tracked in the implementation plan. The 256 items/tick buffer maximum, per-resource link caps and Advanced throughput upgrades remain open (ADR 0048).
